# Исходный код

Сюда следует перенести исходный код из разделов «Код программы» отчётов М2 и М3:

- `main.py` — интерфейс Tkinter, расчёт сетевого графика и имитационное моделирование;
- `report.py` — CSV-выгрузки;
- `txt_report.py` — текстовые отчёты.

Отдельные исходные `.py`-файлы не были приложены к задаче, поэтому этот каталог намеренно не содержит реконструированного кода. Это сохраняет точность портфолио: документация не выдаёт вручную переписанный фрагмент отчёта за исходный рабочий проект.
