# Тест-план

Испытания основаны на программе и методике испытаний из отчёта М2. Проверяется расчёт ранних и поздних сроков событий, резервов и корректность критического пути.

| Сценарий | Длительности b1-b13 | Ожидаемый итоговый срок | Контрольные результаты |
| --- | --- | ---: | --- |
| Базовый | 4, 6, 5, 6, 3, 8, 8, 7, 10, 5, 12, 9, 0 | 30 | Критический путь `b1, b2, b6, b8, b10`; для события 4: ранний 13, поздний 17, резерв 4. |
| Сценарий 2 | 4, 4, 4, 8, 3, 8, 7, 6, 8, 4, 14, 11, 0 | 26 | Для события 4: ранний 11, поздний 12, резерв 1. |
| Сценарий 3 | 5, 4, 6, 4, 3, 7, 8, 5, 7, 3, 8, 10, 0 | 24 | Для события 4: ранний 12, поздний 13, резерв 1. |
| Сценарий 4 | 5, 4, 6, 6, 4, 9, 10, 5, 10, 7, 14, 11, 0 | 30 | Для события 4: ранний 13, поздний 13, резерв 0. |
| Сценарий 5 | 5, 5, 3, 5, 3, 7, 8, 8, 13, 5, 13, 9, 0 | 30 | Для события 4: ранний 13, поздний 17, резерв 4. |

## Критерии приёмки

- значения ранних и поздних сроков совпадают с ожидаемыми;
- резерв события вычисляется как разность позднего и раннего срока;
- критическими отмечаются работы с нулевым резервом;
- CSV и текстовый отчёт соответствуют введённым длительностям и результатам расчёта.
